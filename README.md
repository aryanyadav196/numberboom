# NumberBoom 🎯

A fast-paced casual arcade web game built with HTML, CSS, and JavaScript.

## 🎮 About the Game

NumberBoom is a speed and focus game where random numbers appear on the screen and the player must quickly find and tap the target number shown at the top.

The game is designed to be fast, simple, and fun while keeping the gameplay fair.

## ✨ Features

- 🎯 Target number hunting
- ⏱️ Timer-based gameplay
- ➕ Time bonus for correct clicks
- 💣 Bomb buttons that instantly end the game
- 😄 Funny fake buttons and identities
- 🛡️ Guaranteed target spawn system
- ⚡ Dynamic button spawning
- 📱 Simple browser-based gameplay

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Start the game.
2. Look at the target number displayed at the top.
3. Find the matching number on the screen.
4. Click it as quickly as possible.
5. Avoid bomb and fake buttons.
6. Try to achieve the highest score.
